# Test data — airline-booking

Open `index.html`. 225 rows in 1 objects (matches the report's 225), 1 calls, 7 journeys, 10 failures.

- `objects/<object>/` records · cases · rejections · calls · events · shapes
- `journeys/` test flows: from the repository's tests, staged scenarios, and across services
- `failures/` error replication: the exception, where it is thrown, the call that triggers it, the status to expect
- `exports/` SQL and CSV of the same rows
- `vocabulary/` the domain values the records came from
